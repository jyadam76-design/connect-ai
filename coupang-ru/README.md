# Coupang по-русски (쿠팡 러시아어 검색 도우미)

러시아어권 사용자가 **러시아어로 입력(또는 음성)** 하면 한국어 검색어로 번역해 **쿠팡 검색 결과를 바로 열어주는** 모바일 웹앱(PWA)입니다. 서버가 필요 없는 정적 파일이라 GitHub Pages 등에 그대로 올리면 됩니다.

## 기능
- 🔎 **러→한 검색**: 러시아어 입력/음성(ru-RU) → 한국어 검색어 → `쿠팡에서 검색` 버튼 한 번
  - 번역 결과를 직접 고칠 수 있고, 한국어 → 러시아어 **역번역으로 검증** 표시
  - `📱 В приложении`: 검색어를 복사하고 m.coupang.com 링크로 이동 (설치된 쿠팡 앱이 열리면 붙여넣기)
- 📚 **쇼핑 전용 사전** (`dict.js`, 약 250개 단어): 기저귀·라면·선크림 등 자주 찾는 상품은 쇼핑 검색에 맞는 단어로 정확히 변환. 인터넷이 안 될 때도 동작
- 🇰🇷→🇷🇺 **상품명/리뷰 이해하기**: 쿠팡 앱에서 복사한 한국어를 러시아어로 번역
- 📖 **쿠팡 용어집**: 로켓배송, 장바구니, 반품/교환 등 앱 화면 단어 설명
- 최근 검색 기록, 인기 카테고리 버튼, 홈 화면 설치(PWA), 다크 모드

## 번역 엔진 순서
1. 쇼핑 사전 정확 일치 → 2. Google 번역(무료 엔드포인트) → 3. MyMemory → 4. 사전 단어 단위 번역(오프라인)

> 무료 번역 엔드포인트는 사용량이 많아지면 제한될 수 있습니다. 정식 서비스로 키울 때는 Papago/Google Cloud Translation/Claude API 같은 유료 API를 서버(프록시) 뒤에 두는 것을 권장합니다.

## 실행
```bash
cd coupang-ru && python3 -m http.server 8080   # http://localhost:8080
```
배포: 이 폴더를 GitHub Pages / Netlify / Vercel에 올리면 끝. 링크 공유 시 `?q=подгузники` 처럼 검색어를 미리 넣을 수도 있습니다.

## 참고
쿠팡 공식 앱/API와 제휴된 서비스가 아니며, 쿠팡 검색 페이지 링크만 열어줍니다. 앱 이름·아이콘에 쿠팡 로고를 쓰지 않도록 주의하세요.
