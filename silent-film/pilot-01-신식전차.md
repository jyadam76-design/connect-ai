# 경성 변사극장 · 파일럿 1화 「신식 전차」 (30초)

> 형식: 9:16 세로 · 흑백 무성영화 · 래그타임 피아노 + 효과음 (+ 선택: 변사 해설)
> 세계관: 1927년 경성. 동물 주민들이 신식 문물에 적응하느라 소동을 벌인다.

---

## 1. 캐릭터

### 오덕삼 (주인공 · 당하는 역)
| 항목 | 설정 |
|---|---|
| 동물 | 흰색 페킨 오리, 사람 크기, 통통한 서양배 체형 |
| 성격 | 가난하지만 체면은 끝까지 지키는 '신식 신사' 지망생 |
| 욕망 | 신식 문물을 누리는 모던보이가 되는 것 |
| 결핍 | 돈이 없고, 몸이 신식 문물에 안 맞는다 |
| 시그니처 1 | **머리에 비해 너무 작은 갓** (끈으로 턱에 매달려 있음) |
| 시그니처 2 | **비뚤어진 나비넥타이** + 한복 저고리 위 낡은 양복 조끼 → 신구 문물 충돌 |
| 소품 | 늘 멈춰 있는 고장 난 회중시계, 물갈퀴에 안 맞는 작은 고무신 |
| 걸음걸이 | 뒤뚱뒤뚱, 급하면 엉덩이를 좌우로 크게 흔들며 종종걸음 |
| 반복 개그 | 넘어지고 나면 **작은 갓을 털어 다시 쓰고 관객에게 정중히 인사** |

### 꽥만이 (조연 · 라이벌 겸 구원자)
| 항목 | 설정 |
|---|---|
| 동물 | 덩치 큰 회색 툴루즈 거위 |
| 직업 | 인력거꾼 |
| 성격 | 무뚝뚝하고 심드렁하지만 속정 깊음. 덕삼을 한심하게 보면서도 매번 도와줌 |
| 시그니처 | 흰 무명 머리띠, 어깨에 걸친 수건, 반쯤 감긴 눈 |

### 변사 해설 버전 (선택)
변사를 넣는다면 인터타이틀 2장을 빼고 아래 대사를 얹는다. 해설은 짧게, 화면과 겹치지 않게.
- S1: "자아, 오늘의 주인공 오덕삼 씨! 신식 전차를 타 보겠다고 나섰는데에—"
- S4 끝: "아아, 문명은 돈이 드는 것이었으니!"
- S6: "그래도 체면만은 잃지 않는 우리 오덕삼 씨. 다음 이 시간에!"

## 4. 제작 파이프라인

1. **레퍼런스 고정** — 설정화·표정 시트 확정 (이번 단계)
2. **컷별 키프레임** — S1~S6 시작 프레임을 레퍼런스 이미지 기반으로 생성
3. **영상화** — 키프레임 → image-to-video (컷당 3~5초). 몸개그 타이밍이 중요한 S2·S3·S5는 직접 찍은 동작 영상을 모션 컨트롤로 입히는 방식 권장
4. **후반** — 18fps 느낌으로 프레임 레이트 조정, 그레인·스크래치·플리커 오버레이, 인터타이틀 삽입
5. **사운드** — 래그타임 피아노 BGM + 효과음 (ElevenLabs), 선택적으로 변사 해설
6. **업로드** — 첫 3초에 움직임, 마지막 종소리로 루프 유도

## 5. 1화 이후 확장 (같은 공식: 신식 문물 × 실패 3연타 × 3cm 반전 × 인사)
- 2화 「신식 사진관」 — 플래시가 터질 때마다 눈을 감는 덕삼
- 3화 「신식 다방」 — 커피를 처음 마시고 털이 곤두서는 덕삼
- 4화 「신식 전화」 — 문어 교환원 등장, 전화선이 엉켜 대소동
