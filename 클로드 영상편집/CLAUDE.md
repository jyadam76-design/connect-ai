# 클로드 영상편집 작업실 — Claude 작업 규칙

이 폴더는 Claude Code가 영상을 편집하는 작업실이다. 사용자가 이 폴더를 Claude Code(로컬)로 열고 채팅으로 지시한다.

## 폴더 구조
| 폴더 | 용도 | 규칙 |
|---|---|---|
| `원본영상/` | 사용자가 찍은 원본 (mov/mp4) | **절대 수정·삭제 금지.** 읽기만 한다 |
| `레퍼런스/` | 참고할 스타일 영상 (yt-dlp로 받음) | 스타일 분석용. 내 영상에 그대로 쓰지 않는다 (저작권) |
| `작업중/` | 컷 편집본, 자막 파일, 프레임 캡처, Remotion/HyperFrames 프로젝트 | 중간 산출물 전부 여기 |
| `완성본/` | 최종 mp4 | 파일명: `YYYYMMDD_제목_v1.mp4`, 수정 시 v2, v3… (덮어쓰지 않음) |
| `내 스타일 가이드.md` | 레퍼런스 분석 결과 = 편집 규칙 | 모든 편집은 이 문서를 따른다 |

## 도구
- **FFmpeg** — 컷 편집, 무음 구간 제거, 오디오 정규화, 합치기, 내보내기
- **Whisper** — 음성 → 자막 (한국어는 `--language ko`, 모델 `medium` 이상 권장). 단어 단위 타임스탬프로 컷 지점 찾기
- **yt-dlp** — 레퍼런스 영상 다운로드 → `레퍼런스/`
- **Remotion** — React 코드로 모션그래픽/자막 애니메이션/완성 영상 렌더링
- **HyperFrames** — HTML로 모션그래픽 작성 → MP4 렌더 (`npx hyperframes`)

도구가 없으면 `scripts/check.sh`(맥) 또는 `scripts\check.ps1`(윈도우)를 실행해 무엇이 빠졌는지 확인하고 사용자에게 설치를 안내한다.

## 1단계: 레퍼런스 분석 (사용자가 링크 3개 정도를 주면)
1. `yt-dlp -f "bv*[height<=1080]+ba/b" -o "레퍼런스/%(title).50s.%(ext)s" <링크>` 로 다운로드
2. 각 영상을 분석:
   - `ffmpeg -i 영상 -vf "fps=1,scale=360:-1,tile=6x3" 작업중/ref_sheet_%02d.jpg` 로 프레임 시트를 만들어 직접 본다
   - 장면 전환 빈도: `ffmpeg -i 영상 -vf "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep pts_time`
   - Whisper로 대본을 뽑아 말 속도·훅 구조·전개를 본다
3. 공통점을 `내 스타일 가이드.md`에 정리한다 (컷 템포, 자막 폰트/색/위치/강조 방식, 모션그래픽 종류, 화면 구성, 오프닝 훅, 엔딩 CTA, BGM/효과음). **구체적 수치로** 쓴다 (예: "평균 컷 길이 1.8초", "자막 1줄 최대 10자, 핵심 단어 노란색").

## 2단계: 편집 (사용자가 원본을 넣고 지시하면)
1. `ffprobe`로 원본 정보 확인 (해상도, fps, 길이, 세로/가로)
2. Whisper로 전체 자막(SRT + 단어 타임스탬프 JSON)을 `작업중/`에 생성
3. **컷 편집**: 무음(`silencedetect=noise=-35dB:d=0.4`), 말 더듬기, 반복·NG 구간을 제거한 컷 리스트를 만들고, 먼저 사용자에게 "이 구간들을 자릅니다" 요약을 보여준다
4. **전개**: 첫 3초 훅이 약하면 강한 문장을 앞으로 올리는 안을 제안한다
5. **모션그래픽**: 스타일 가이드에 맞춰 Remotion(또는 HyperFrames)으로 제목 카드, 키워드 팝업, 로고/스크린샷 카드, 진행 배지 등을 만든다
6. **자막**: 스타일 가이드대로 번인 자막 (Remotion 컴포넌트 또는 ASS 자막 + ffmpeg)
7. **오디오**: `loudnorm=I=-14:TP=-1.5:LRA=11` 로 정규화
8. 렌더 → `완성본/` 에 저장하고, 미리보기용 프레임 시트를 만들어 직접 확인한 뒤 결과를 보고한다

## 3단계: 수정
사용자가 채팅으로 "3초쯤 자막 틀렸어", "모션 더 빠르게" 처럼 말하면 해당 부분만 고치고 새 버전(v2…)으로 렌더한다. 수정 내용이 반복되는 취향이면 `내 스타일 가이드.md`에도 반영한다.

## 주의
- 기본 출력: 세로 숏폼 1080x1920, 30fps, H.264 + AAC, `-movflags +faststart`
- 남의 레퍼런스 영상의 장면·음악·로고를 내 영상에 넣지 않는다. 스타일만 참고한다
- 저작권 있는 음악을 임의로 넣지 않는다. BGM은 사용자가 제공한 파일이나 라이선스 확인된 소스만 쓴다
