# 🎬 클로드 영상편집 작업실

Claude Code가 컷 편집, 모션그래픽, 전개, 자막까지 해주는 영상 편집 폴더입니다.

## 시작하기 (처음 한 번)
1. **Claude 데스크톱 앱**을 설치하고 **Claude Code** 탭을 엽니다.
2. 이 `클로드 영상편집` 폴더를 내 컴퓨터로 받습니다. 리포를 clone하거나 폴더만 복사하면 됩니다.
3. Claude Code에서 **로컬(Local)** 을 고르고 이 폴더를 엽니다. 이제 Claude가 폴더 안 파일을 읽고 저장할 수 있습니다.
4. 도구를 설치합니다. 둘 중 편한 방법을 쓰세요.
   - Claude에게 `프롬프트 모음.md`의 ① 프롬프트를 보내기
   - 터미널에서 직접 실행하기
     - 맥: `bash scripts/setup-mac.sh`
     - 윈도우: `powershell -ExecutionPolicy Bypass -File scripts\setup-windows.ps1`

   설치 중에 Claude가 권한을 물으면 **허용(Allow)** 을 누르세요.

| 도구 | 역할 |
|---|---|
| Remotion | React 코드로 영상과 모션그래픽 만들기 |
| HyperFrames | HTML로 모션그래픽 만들기 → MP4 |
| FFmpeg | 컷 편집, 내보내기 |
| Whisper | 말소리 → 자막 |
| yt-dlp | 레퍼런스 영상 다운로드 |

## 사용법
1. **스타일 학습**: 원하는 스타일의 영상 링크 3개를 넣고 `프롬프트 모음.md`의 ② 프롬프트를 보냅니다. Claude가 영상을 분석해 `내 스타일 가이드.md`를 채웁니다.
2. **편집**: 원본 영상을 `원본영상/`에 넣고 ③ 프롬프트를 보냅니다. 결과물은 `완성본/`에 저장됩니다.
3. **수정**: 고칠 곳을 채팅으로 말하면 v2, v3 버전으로 다시 저장합니다.

Claude가 따르는 상세 규칙은 `CLAUDE.md`에 있습니다.

> 레퍼런스 영상은 스타일 참고용입니다. 남의 영상 장면이나 음악을 그대로 쓰면 저작권 문제가 생깁니다.
